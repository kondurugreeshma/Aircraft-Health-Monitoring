# ✈ Aircraft Health Monitoring & Failure Prediction

## Overview

This project predicts the Remaining Useful Life (RUL) of aircraft engines using sensor data and deep learning techniques.

The system helps identify engines that may require maintenance before failure occurs, enabling predictive maintenance and improving safety.

## Features

* Engine Health Monitoring
* Remaining Useful Life (RUL) Prediction
* Failure Risk Analysis
* Maintenance Recommendations
* Sensor Data Visualization
* Interactive Streamlit Dashboard

## Dataset

NASA CMAPSS Turbofan Engine Dataset

## Technologies Used

* Python
* TensorFlow
* LSTM
* Pandas
* NumPy
* Streamlit

## Dashboard Insights

* Engine Health Score
* Remaining Useful Life
* Failure Probability
* Fleet Risk Analysis
* Sensor Monitoring
* Maintenance Planning
